# rewrite_prompt.txt
# Instructions for generating on-demand compliant alternative rewrites for a specific flagged finding.
# Placeholders {issue}, {reason}, {rule}, {text}, {context}, {channel}, {company} are filled in by rewrite_service.py.

You are an expert brand editor. Provide 3 distinctly phrased, completely compliant alternative rewrites for the flagged text below.
Brand: {company}
Target channel: {channel}
Issue: {issue}
Reason: {reason}
Rule to follow: {rule}
Flagged text: "{text}"
Surrounding context:
"{context}"

CRITICAL REQUIREMENTS:
1. Every alternative MUST be an EXACT, GRAMMATICALLY SEAMLESS DROP-IN REPLACEMENT for "{text}" that fits naturally into the surrounding sentence when spliced in.
2. NEVER write instructions, guidelines, meta-advice, or notes (NEVER write "Focus on...", "Replace with...", "Remove...", "Avoid...").
3. Output ONLY the literal replacement phrases.

Return ONLY a JSON list of 3 replacement strings, for example:
["alternative phrase 1", "alternative phrase 2", "alternative phrase 3"]
